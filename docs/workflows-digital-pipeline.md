# Digital Pipeline

В событиях запуска появился отдельный тип `digital-pipeline` — Digital Pipeline.
Он может быть основным или дополнительным стартом потока. Настроек у стартовой
ноды нет: условия срабатывания задаются в автоматизации воронки amoCRM.

Список виджета в воронке запрашивает `source=digital-pipeline` и показывает только
включённые потоки текущего аккаунта с таким стартом. Callback также проверяет тип
старта и запускает только DP-ветки. Ручные старты не выполняются. Массовый ручной
запуск из списка сделок продолжает использовать только ручные старты.

Существующие потоки и сохранённые действия воронки автоматически не меняются:
нужно добавить Digital Pipeline в нужный поток и выбрать его в настройках amo.

Клиент amo распространяется внутри ZIP. После публикации серверных изменений
нужно обновить интеграцию пакетом версии 1.0.36, иначе установленный старый клиент
не передаст новый фильтр списка. Сборка: из `application/` выполнить
`node scripts/build-workflow-widget.mjs`. Обновляются оба публичных ZIP.

Локальные проверки используют изолированную SQLite и подменённую очередь.
Реальный callback из amoCRM и визуальная проверка в браузере отдельно не выполнены.

Селектор кнопок использует `source=amo-button`; запуск с этим источником проверяет
тот же тип и выполняет только ветку кнопки. Видимость кнопок в карточках по-прежнему
отключена. Потоки с кнопочным стартом можно подготовить и включить, но текущий
клиент не отображает кнопки в сделке.

В редактор добавлена активация: сохранение текущих правок без перехода со страницы,
с теми же проверками подключения amoCRM и корректности потока. В истории убраны
переключатель темы и дублирующие иконки. Импорт и создание — текстовые кнопки.

Подстановки генерируются по имени ноды: `{{ $node["Название"].json.items[0].id }}`.
Одноимённые ноды различаются суффиксом `(2)` и далее. Старые ID-ссылки выполняются
как раньше; при открытии настройки переводятся в имена. При переименовании ноды
редактор обновляет созданные им подстановки. Исходный JavaScript не переписывается.
