# Связи ноды «Цикл»

- «Каждый элемент» запускает подключённую ветку с первым элементом списка.
- Следующий элемент берётся только после фактически выполненной обратной связи во вход этого цикла. Неисполненная ветка условия не считается возвратом.
- Без возврата ветка выполняется один раз и останавливается. Это правило действует и для старых JSON без `require_return`, и при `require_return: false`.
- «Готово» запускается после возврата с последнего элемента. Пустой список сразу запускает «Готово». Отключённый цикл также пропускает тело и идёт в «Готово».
- «Готово» можно соединить с любой нодой, в том числе предыдущей, другой веткой или самим циклом. Обратное соединение запускает новый проход с актуальными входными данными. Это не повторное использование прежнего результата проверки. Возврат в активный внешний цикл берёт его следующий элемент.
- Режим «Один раз» ограничивает список первым элементом; запуск отдельной ноды из редактора проверяет только первый элемент без выполнения «Готово».

Ноды внутри цикла могут иметь входы из других веток. Нет запрета на общие ноды для двух циклов. Внешний путь выполняется отдельно от итераций; `$json` использует входы, которые реально сработали в текущем проходе. Если одновременно сработали несколько входов, нужно указать данные конкретной ноды.

Если внешний путь дошёл до входа ещё не запущенного цикла через общую ноду, цикл запускается с этого входа. Уже обработанный цикл не запускается повторно от другой сходящейся ветки в том же проходе. Несколько возвратов в одной итерации запрашивают следующий элемент только один раз.

Вложенные циклы сохраняют отдельные состояния. Идентификаторы выполнений включают путь итераций и повторных проходов через «Готово», поэтому возобновление запуска использует сохранённые результаты без повторной записи в CRM. Сохраняются ограничения: до 1000 элементов, 8 уровней вложения и 5000 выполнений нод. Произвольная замкнутая связь без ноды «Цикл» по-прежнему недопустима. В тестовом запуске схемы с обратными переходами через «Готово» выполняются целиком с журналом каждого прохода; тест одной ноды по-прежнему ограничен первым элементом.

## Данные и общая переменная веток

Первый и последний элемент доступны через `{{ $("Найти контакты").first().id }}` и `{{ $("Найти контакты").last().id }}`. Также работают `.first.id` / `.last.id`. Старые `[0]` сохраняют поддержку. Для пустого списка результат `null`, для одного объекта `first()` и `last()` возвращают сам объект.

Добавьте «Присвоить» в каждую альтернативную ветку, задайте одинаковое имя `contact_id` и значение из нужной ноды. После схождения используйте `{{ $vars.contact_id }}`. Присваивание сохраняет тип значения. Переменные доступны дальше по текущему проходу; изменения внутри итерации не переносятся в следующий элемент, за пределы ближайшего цикла или в другой запуск. Изначальные значения, заданные до цикла, доступны внутри него. Это локальная переменная выполнения, не глобальное хранилище.

Изменение не переписывает сохранённые схемы и не добавляет обратные связи автоматически. Перед включением старого потока проверьте замыкание веток, которые должны обработать весь список.
