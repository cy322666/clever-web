# Единый исходный код

GitHub `master`, основная локальная папка и production используют один релизный
коммит. Код на сервере не редактируется. Правила обязательны в `AGENTS.md`.

При сверке 08.10.2026 за основу взят полный работающий production, включая
переопределения `resources/views/vendor` и `resources/lang/vendor`, которые
ошибочно пропускал прежний экспорт. Добавлены отсутствовавшие локальные тесты,
документация и исходники пакета отраслевой интеграции. Новые изменения runtime
относительно текущего production не включались автоматически по результату merge.

Старый локальный исходный код сохранён отдельно перед заменой. Устаревшие варианты
онбординга, авторизации, интерфейса и ранее удалённый GetCourse не возвращены в
работающий production. Резервная версия не является веткой для дальнейшего деплоя.

Перед завершением релиза проверить:

1. `git rev-parse HEAD` одинаков на локальной машине, в GitHub `master` и на сервере.
2. `bash ops/deploy/assert-clean-tree.sh` проходит в основной локальной папке и на сервере.
3. Сборка получена из того же SHA, указанного в `application/public/build/.source-commit`.
4. `/up`, `app:smoke --strict` и Horizon работают.

Полный набор исторических тестов на момент сверки имеет ошибки и несовпадения
с текущим production. Это не повод обходить CI или ослаблять проверки доступа.
Проверки последних runtime-правок запускаются отдельно; старые несоответствия
нужно исправлять отдельными проверяемыми коммитами.
