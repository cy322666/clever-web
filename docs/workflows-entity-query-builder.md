# Конструктор запросов сущностей

В «Запросы → сущность → Получить список» добавлен режим «Конструктор» для задач, сделок, контактов, компаний и покупателей. Новые ноды открываются с этим режимом. Старые ручные параметры и JSON не преобразуются автоматически.

Фильтр: поле → условие → значение / переменная. Поля зависят от выбранной сущности. У этапа сделки дополнительно выбирается воронка; оба значения принимают переменные. Ответственные, воронки, этапы, типы задач и варианты допполей выбираются из справочников текущего аккаунта.

Открытые задачи сделки:

- Тип связанной сущности = Сделка.
- ID связанной сущности = `{{lead.id}}`.
- Статус задачи = Открыта.

Числовые поля и даты поддерживают «Равно», «От», «До». Разные поля соединяются через И, повторные значения списочного поля — через ИЛИ. Переменная может вернуть массив ID для списочного фильтра. Произвольных групп ИЛИ, «не равно» и «содержит» нет: они не выдаются за поддерживаемые API-операторы. Для текстового поиска сущностей есть отдельное поле «Поиск» (кроме задач).

Выборка постраничная: 1–250 записей, номер страницы и сортировка. Выход ноды остался прежним: `items`, `count`, `has_more`, `data`. Автоматического сбора всех страниц нет.

В новых запросах доступны «Конструктор» и ручные «Параметры». GET не получает JSON-тело: прежний JSON всегда преобразовывался в параметры URL. Обычный старый JSON при открытии редактора теперь раскладывается в строки параметров с сохранением строки запроса; полная динамическая подстановка остаётся в режиме «Сохранённый запрос», чтобы не потерять действующие настройки. Преобразование сохраняется только после сохранения ноды. Допполя доступны только для своей сущности и своего пользователя. Сначала обновите справочники кнопкой ноды, если поля отсутствуют.

Расширенные фильтры сделок, контактов, компаний и покупателей требуют доступной API-фильтрации amoCRM. Источники: [фильтрация](https://www.amocrm.ru/developers/content/crm_platform/filters-api), [задачи](https://www.amocrm.ru/developers/content/crm_platform/tasks-api).

Проверки: изолированная SQLite, Livewire-рендер схемы, сохранение ноды, подстановка переменных, mock GET, разделение сущностей/пользователей, отклонение несовместимых условий, совместимость старых параметров и JSON. Ручной браузерный прогон и реальные запросы amoCRM не выполнялись.

Выложено 12 сентября 2026: `/home/clever-releases/20260912-query-release-CfAOSX`, шесть файлов с резервной копией и проверкой хешей. Перед выкладкой повторно прошли 42 PHP-теста (386 проверок). Сборщик запроса открытых задач проверен в production-контейнерах app и supervisor без сети и базы; оба `app:smoke --strict` прошли. Без миграций и режима обслуживания.

Последующие изменения пока локальные: утолщённая иконка задач, отсутствие переключателя темы в редакторе, отказ от нового JSON-режима в GET с сохранением прежних конфигураций.
