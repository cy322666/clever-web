# Инструменты редактора «Потоков»

## Справочники ноды

Кнопка со стрелкой обновления находится рядом с «Запустить ноду» в настройках amoCRM-действия.
Используется только активное подключение текущего пользователя. По типу ноды выбираются справочники:

- Сделка: поля, теги, ответственные, воронки и этапы.
- Контакт / компания: поля и теги этой сущности, ответственные.
- Смена статуса: только воронки и этапы.
- Задача: ответственные и типы задач.
- Salesbot: список ботов, с заменой кеша списка.
- Запросы amoCRM: по выбранному ресурсу (сделки, контакты, компании, воронки, пользователи, боты).

Если форма не использует справочники, кнопка недоступна. Обновление не запускает действие и не перезаполняет форму.
Все страницы загружаются до изменения локального справочника; ошибка оставляет старые записи. Предел — 5000 записей на справочник.
Для списка пользователей amoCRM нужны права администратора интеграции.

Документация: [пользователи](https://www.amocrm.ru/developers/content/crm_platform/users-api), [воронки](https://www.amocrm.ru/developers/content/crm_platform/leads_pipelines), [типы задач](https://www.amocrm.ru/developers/content/crm_platform/account-info), [Salesbot](https://www.amocrm.ru/developers/content/api/salesbot-api).

## Название, теги, папка

Нажать название в шапке → ввести новое → Enter или выйти из поля. Escape отменяет ввод.
Иконка тега открывает добавление по Enter и удаление существующих тегов. До 20 тегов по 50 символов.
Иконка папки открывает одиночный выбор из своих папок, включая «Без папки».
Для сохранённого потока эти изменения сохраняются сразу, не затрагивая несохранённые ноды или активность.
Для нового потока значения сохранятся при создании. Теги лежат в `definition.tags`, папка — в существующем `group_name`; миграции не нужны.

## Экспорт и импорт

Меню «…» в редакторе: «Экспорт JSON» / «Импорт JSON». Импорт также доступен в шапке списка сценариев.
Формат — `clever-flows`, версия 1, до 2 МБ. Это формат платформы, не формат n8n.
Экспорт включает текущую схему, связи, описание, теги и размещение нод.
Импорт всегда создаёт новый выключенный поток текущего пользователя; папка выбирается отдельно.
Проверяются типы нод, уникальность ID, связи, циклы, ограничения графа и координаты.

Из файла удаляются служебные токены, пароли и HTTP-заголовки. После импорта их нужно заполнить заново.
Тексты, JavaScript и URL сохраняются: перед передачей файла проверьте, нет ли секретов внутри них.
Перед включением чужого файла проверьте все действия и код. Импорт не запускает ноды и не переносит историю или подключения другого пользователя.
