# amoCRM entity icons

Original navigation assets from the official amoCRM/Kommo UI stylesheet:
https://cfcdn.kommo.com/frontend/build/67501.292ee90daf672369.css

Retrieved 2026-09-12 through the publicly accessible login page at https://demo.amocrm.ru/.
Source variables: `--icon-nav-menu-leads`, `--icon-nav-menu-customers`, `--icon-nav-menu-todo`, `--icon-nav-menu-catalogs`.

The lead and catalog assets retain their original paths and viewBoxes. The deal outline uses a 1.4 stroke for legibility at node-icon size. The task and customer icons were redrawn on 2026-09-13 as filled discs with white checkmark/people details, matching the user-approved conversation icon style; these two are adapted illustrations, not unchanged official assets. `workflow-icon` gives each inline SVG independent clipping IDs and colors active amoCRM glyphs #339dc7 (sampled from the supplied logo); disabled nodes stay gray. These assets identify amoCRM entities in the workflow integration; they do not imply affiliation.
