# Workflow node icons

Unmodified SVG assets from `@phosphor-icons/core` 2.1.1 (MIT).
Source: https://github.com/phosphor-icons/core
Package: https://registry.npmjs.org/@phosphor-icons/core/-/core-2.1.1.tgz

Only the selected fill, bold and duotone icons are vendored. The workflow card composes an entity silhouette and an action cue using these original icons. No network or JavaScript icon dependency is required. Other application icons are unchanged.
