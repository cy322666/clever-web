# Workflow node icons

Unmodified SVG assets from `@phosphor-icons/core` 2.1.1 (MIT).
Source: https://github.com/phosphor-icons/core
Package: https://registry.npmjs.org/@phosphor-icons/core/-/core-2.1.1.tgz

Only the selected fill, bold and duotone icons are vendored. The workflow card uses opaque outlines and a separate operation cue. Duotone backing fills are hidden, so the shapes stay clear in both themes. The original SVG files remain unchanged. No network or JavaScript icon dependency is required. Other application icons are unchanged.

Telegram exception: telegram-logo-brand.svg reuses the plane path from resources/svg/services/telegram.svg, normalized to the shared 256-unit view box and a single currentColor fill.
