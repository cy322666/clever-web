# Правила работы

- Отвечай коротко. Не используй длинное тире и символ рубля, пиши «руб.».
- Основная рабочая папка: `/Users/integrator/PhpstormProjects/clever-web`.
- GitHub `master` является источником кода для продакшена. После завершённой выкладки основная локальная папка, GitHub `master` и `/home/clever-web` должны указывать на один коммит и иметь чистое состояние исходного кода.
- Любая правка: локальный код, проверки, коммит, push в GitHub, затем выкладка именно этого коммита. Запрещены ручные изменения исходников на проде, копирование отдельных исправленных файлов и применение незакоммиченных патчей по SSH.
- Перед работой сверяй локальный HEAD, GitHub и прод. При расхождении сначала сохраняй обе версии и разбирай отличия. Не продолжай разработку из устаревшей копии.
- Деплой должен отказываться работать с незакоммиченными или неучтёнными исходниками. Не обходи проверку чистоты и не используй `reset --hard`, `clean` или принудительную перезапись для сокрытия расхождений.
- Если используется временная ветка/копия, результат обязательно возвращается в основную локальную папку. Сохранение независимых веток не считается синхронизацией.
- Не включай в Git секреты, `.env`, `auth.json`, БД, логи, пользовательские загрузки, резервные копии и зависимости. Сборки создаются из того же коммита, что развёрнут на проде.
- Перед выкладкой сохраняй возможность отката. После неё проверяй точный SHA, отсутствие изменений исходников, сборку, доступность приложения и очередь. Настройки окружения и рабочие данные не обязаны совпадать с локальными и не заменяются.
